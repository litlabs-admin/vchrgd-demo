POPUP PLACEMENT
- Across the site: open Squarespace's site-wide Code Injection panel and add the complete individual popup embed to Footer. Preserve other code already in that field. Remove the old popup Code block to avoid duplicates.
- One page only: use a Code block on that page, not the shared site footer. The updated script moves the popup outside the section so it floats against the browser window.
- The popup starts hidden and appears five seconds after the page finishes loading. If inserted after load, it waits five seconds from insertion. Change displayDelayMs = 5000 in the script to adjust the delay (milliseconds).
- The popup can be dismissed. Dismissal is not remembered across full page reloads; there is no once-per-session setting.
- Code Injection requires a supported Squarespace plan and does not run on Squarespace checkout pages.
- Use the individual popup embed, not the combined test pack, for installation.
